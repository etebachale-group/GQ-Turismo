# ADR-002: Motor de Base de Datos: MySQL / MariaDB

**Decisión Asociada:** D2
**Estado:** Aceptada
**Fecha:** 2026-10-31

## Contexto
GQ-Turismo requiere una plataforma escalable, mantenible y segura para dinamizar el sector turístico de Guinea Ecuatorial.

## Decisión
Se mantiene MySQL 8 / MariaDB como motor relacional, compatible con el entorno local XAMPP y servidores VPS estándar. Todas las tablas se gestionarán estrictamente con migraciones versionadas.

## Consecuencias
- **Positivas:** Estándares modernos de desarrollo, robustez ante fallos, seguridad por diseño y facilidad de testing.
- **A considerar:** Requiere etapa de migración planificada y disciplina estricta de trabajo por tareas.
