# ADR-001: Elección del Stack Backend: Laravel LTS

**Decisión Asociada:** D1
**Estado:** Aceptada
**Fecha:** 2026-10-31

## Contexto
GQ-Turismo requiere una plataforma escalable, mantenible y segura para dinamizar el sector turístico de Guinea Ecuatorial.

## Decisión
Se adopta Laravel LTS sobre PHP 8.2+/8.3+. Provee arquitectura robusta, Eloquent ORM con consultas preparadas por defecto, sistema de migraciones, autenticación nativa, validaciones con Form Requests y soporte para colas.

## Consecuencias
- **Positivas:** Estándares modernos de desarrollo, robustez ante fallos, seguridad por diseño y facilidad de testing.
- **A considerar:** Requiere etapa de migración planificada y disciplina estricta de trabajo por tareas.
