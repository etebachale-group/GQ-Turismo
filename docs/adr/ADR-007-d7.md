# ADR-007: Almacenamiento de Montos Financieros: Enteros

**Decisión Asociada:** D7
**Estado:** Aceptada
**Fecha:** 2026-10-31

## Contexto
GQ-Turismo requiere una plataforma escalable, mantenible y segura para dinamizar el sector turístico de Guinea Ecuatorial.

## Decisión
El XAF no utiliza fracciones decimales (centavos). Los importes se gestionarán y almacenarán como enteros en la unidad mínima para evitar errores de redondeo en operaciones de cálculo y comisiones.

## Consecuencias
- **Positivas:** Estándares modernos de desarrollo, robustez ante fallos, seguridad por diseño y facilidad de testing.
- **A considerar:** Requiere etapa de migración planificada y disciplina estricta de trabajo por tareas.
