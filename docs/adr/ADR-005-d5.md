# ADR-005: Abstracción de Pagos: Interfaz PaymentGateway

**Decisión Asociada:** D5
**Estado:** Aceptada
**Fecha:** 2026-10-31

## Contexto
GQ-Turismo requiere una plataforma escalable, mantenible y segura para dinamizar el sector turístico de Guinea Ecuatorial.

## Decisión
Se diseña una interfaz desacoplada PaymentGateway. Se implementará un driver inicial de pago manual con comprobante y auditoría, preparado para conectar pasarelas bancarias locales o internacionales vía webhooks.

## Consecuencias
- **Positivas:** Estándares modernos de desarrollo, robustez ante fallos, seguridad por diseño y facilidad de testing.
- **A considerar:** Requiere etapa de migración planificada y disciplina estricta de trabajo por tareas.
